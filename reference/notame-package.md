# `notame` package.

Provides tabular data preprocessing and data wrangling functionality for
untargeted LC-MS metabolomics research.

## References

Klåvus et al. (2020). "notame": Workflow for Non-Targeted LC-MS
Metabolic Profiling. Metabolites, 10: 135.
